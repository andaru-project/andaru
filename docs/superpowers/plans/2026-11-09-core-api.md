# Local Engine API and Live Interface Inventory Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Execution method requires owner approval; Native is recommended for this small, sequential slice, followed by one condensed adversarial branch review.

**Goal:** Deliver a real Go engine, root-local HTTP API and CLI that report the Debian host's actual links/addresses without modifying networking or exposing a network listener.

**Architecture:** Start the approved engine/CLI path, not the presentation layer. The engine uses Debian's `ip` read interface, returns a typed JSON snapshot over a protected Unix socket, and enforces Linux peer identity itself. The CLI consumes that API; no UI, database, fake save/apply routes or network realizer is added before it is needed.

**Tech Stack:** Go 1.27.3, standard library only, Debian 13, iproute2, systemd. Module `github.com/andaru-project/andaru`; Linux amd64 qualification, Linux arm64 cross-build. No Go compiler is needed on the deployed VM.

**Spec:** [Approved process model](https://github.com/andaru-project/andaru/issues/5#issuecomment-6698660151), [detailed process/socket boundary](https://github.com/andaru-project/andaru/issues/5#issuecomment-6695223986), [API proposal](https://github.com/andaru-project/andaru/issues/6#issuecomment-6690626377), [product destination](https://github.com/andaru-project/andaru/issues/1). The scoped contract below proposes the first implementation increment; it is not a claim that the full MVP or its network-facing user/session model is implemented.

## Review Focus

1. Malformed, oversized or internally invalid `ip` output must never become a partial or fabricated successful snapshot; Task 1 owns the parser/size cases and Task 2 owns the API error mapping.
2. A non-root or unidentified peer, including one sending forged identity headers, must be denied before inventory is read; Tasks 2–3 own HTTP/context and real-kernel credential proofs.
3. An existing file, symlink or socket at the requested endpoint must survive refused startup untouched; Task 3 owns filesystem/lifecycle cases.
4. A cancelled request or hung child command must terminate within the command deadline and reap the child; Task 1 owns the subprocess cases and Task 3 verifies server shutdown.
5. Transport/HTTP failures must not produce valid-looking CLI stdout, and service restart must not create a TCP listener or leave a stale owned socket; Task 4 owns the actual CLI/systemd proof.

## Scoped Contract and Acceptance

This is a complete read-only core increment, not a firewall yet. Its useful path is real: `andaru ctl links` → engine HTTP over Unix → Debian `ip` → typed host data. No mocked response is a deliverable.

### Transport and commands

- Default socket `/run/andaru/engine.sock`; root-owned parent directory `0700`, socket `0600`. Both `engine` and `ctl` accept `--socket <absolute-path>` for an explicitly selected local test/recovery endpoint. No HTTP-host or arbitrary-command flag.
- Refuse to run the engine as a non-root user. Reject symlink/non-directory/incorrectly owned or permissive endpoint parent directories. Create the final parent directory only if absent, at `0700`; never recursively remove a directory.
- Refuse any pre-existing socket path, including stale sockets. Do not automatically unlink a path that this process did not create. Immediately after bind, explicitly chmod the owned socket to `0600`, regardless of the caller's umask; the already-private `0700` parent protects the bind-to-chmod interval. Disable automatic pathname unlink, retain the bound socket's device/inode ownership evidence, and remove it after listener close only if current `Lstat` still identifies a socket with that device/inode. A replaced path is left untouched. systemd owns runtime-directory cleanup after a crash.
- `andaru engine [--socket PATH]` serves until SIGINT/SIGTERM and shuts down cleanly.
- On requested shutdown, cancel the daemon/request base context, stop accepting connections, and allow HTTP shutdown at most 3 seconds, then force `Close` if needed. Reap cancelled inventory children, finish ownership-checked socket cleanup after listener closure, and map expected `http.ErrServerClosed` to a clean return rather than a restart-worthy failure. Never wait indefinitely for a partial HTTP request or held-open connection.
- `andaru ctl [--socket PATH] links` writes the API's successful JSON snapshot to stdout. `andaru ctl [--socket PATH] openapi` writes the implemented API document. The CLI never calls `ip` directly.
- CLI exit codes: `0` success, `1` transport/API/response failure, `2` invalid command/arguments. Failure diagnostics go to stderr; no partial success JSON on stdout.

### HTTP and schemas

Only two resources are implemented:

| Resource | Success | Failure behaviour |
| --- | --- | --- |
| `GET /api/v1/status/links` | `200`, `{"items":[...]}` | `503 INVENTORY_UNAVAILABLE` for command/parse/size/deadline failure; never partial items |
| `GET /api/v1/openapi.json` | `200`, the actual OpenAPI document | Same peer restriction as status |

HEAD follows the corresponding GET's authorization/status semantics but sends no body. Other methods on known resources return `405 METHOD_NOT_ALLOWED`, `Allow: GET, HEAD`; unknown paths return `404 NOT_FOUND`. Denied or missing peer identity returns `403 FORBIDDEN` before route/method work, including for POST and unknown paths. All errors use `{"error":{"code":"...","message":"...","details":[]}}`; use JSON Content-Type and `Cache-Control: no-store`. Do not return raw subprocess output, private paths or stack traces. Do not add speculative error details or request-body handling.

The OpenAPI 3.1 document lives in `internal/engine/openapi.json` and is embedded by that package. Document exactly these resources, the error envelope, the response types and the Unix/root peer restriction. Transport identity is not an HTTP header security scheme: do not invent an API-key header to represent `SO_PEERCRED`. The `/api/v1` prefix is provisional and does not assert a 1.0 release. No future routes or empty schemas appear in the document.

`items` is a complete host-inventory snapshot, not a persisted configuration collection. Return arrays as `[]`, not `null`; order links by `ifIndex` for deterministic output. This bounded snapshot has no paging controls in this increment. Names and indexes are observed runtime data, **not** immutable configured link IDs or permanent-MAC identities.

```go
type AddressStatus struct {
    Family       string `json:"family"`       // "ipv4" or "ipv6"
    Address      string `json:"address"`      // host address, never network-masked
    PrefixLength int    `json:"prefixLength"`
    Scope        string `json:"scope"`
}

type LinkStatus struct {
    IfIndex     int             `json:"ifIndex"`
    Name        string          `json:"name"`
    LinkType    string          `json:"linkType"`
    MTU         int             `json:"mtu"`
    OperState   string          `json:"operState"`
    Flags       []string        `json:"flags"`
    LinkAddress string          `json:"linkAddress,omitempty"`
    Addresses   []AddressStatus `json:"addresses"`
}
```

`linkAddress` is the current link-layer address if supplied, not a promised permanent Ethernet MAC. Absent link addresses and empty address lists are legitimate, including virtual/down links; do not confuse loopback's observed all-zero address with an absent address. Map tool families `inet` → `ipv4` and `inet6` → `ipv6`, rejecting other families. Read each host IP from `addr_info[].local`, never the top-level link-layer `address`. Preserve observed state text such as loopback `UNKNOWN`; do not fabricate `UP`. Parse IPs with `net/netip`, retaining host bits, and validate family/prefix lengths (IPv4 0–32, IPv6 0–128). Reject duplicate indexes/names, non-positive indexes, missing names/link types/operational states, negative MTUs and invalid address records. Ignore unrelated `ip` JSON fields so distro additions do not break the read adapter; this is not the strict author-manifest parser.

Fixed operational bounds for this first slice: command deadline 2 seconds; stdout cap 4 MiB; retained stderr cap 4 KiB; CLI HTTP timeout 5 seconds and response cap 8 MiB; server ReadHeaderTimeout 5 seconds and IdleTimeout 30 seconds. These are constants, not new settings knobs. Enforce bounds while reading, not after unbounded buffering. Kill/reap a cancelled or oversized child. An unavailable inventory is an explicit failure, not an empty-list fallback or stale cache.

### Task 1: Read real host links through a bounded Debian-tool adapter

**Files:** create `go.mod`, `internal/host/links_linux.go`, `internal/host/links_linux_test.go`.

**Interfaces:** produces the DTOs above and `func ReadLinks(ctx context.Context) ([]LinkStatus, error)`. No public executable override.

Representative assertion contract (extend it with all cases in the steps below):

```go
func TestParseLinksPreservesHostAddresses(t *testing.T) {
    data := []byte(`[
      {"ifindex":2,"ifname":"eth0","link_type":"ether","operstate":"UP","mtu":1500,"flags":["UP"],"address":"02:00:00:00:00:02","addr_info":[{"family":"inet","local":"192.0.2.7","prefixlen":24,"scope":"global"},{"family":"inet6","local":"2001:db8::7","prefixlen":64,"scope":"global"}]},
      {"ifindex":1,"ifname":"lo","link_type":"loopback","operstate":"UNKNOWN","mtu":65536,"flags":["LOOPBACK"],"addr_info":[]}
    ]`)
    got, err := parseLinks(data)
    if err != nil || len(got) != 2 || got[0].IfIndex != 1 || got[1].IfIndex != 2 {
        t.Fatalf("invalid snapshot/order: %#v, %v", got, err)
    }
    if got[0].OperState != "UNKNOWN" || got[0].Addresses == nil || got[0].LinkAddress != "" {
        t.Fatalf("invented state/address or null array: %#v", got[0])
    }
    a := got[1].Addresses
    byFamily := map[string]AddressStatus{}
    for _, address := range a { byFamily[address.Family] = address }
    if len(a) != 2 || byFamily["ipv4"].Address != "192.0.2.7" || byFamily["ipv4"].PrefixLength != 24 ||
        byFamily["ipv6"].Address != "2001:db8::7" || byFamily["ipv6"].PrefixLength != 64 {
        t.Fatalf("lost host bits/family/prefix: %#v", a)
    }
}
```

Representative filesystem safety assertion in the explicitly root-required integration suite:

```go
func TestUnixAPIPreservesExistingFile(t *testing.T) {
    if os.Geteuid() != 0 { t.Fatal("integration suite requires root") }
    path := filepath.Join(t.TempDir(), "engine.sock")
    if err := os.WriteFile(path, []byte("keep"), 0600); err != nil { t.Fatal(err) }
    ctx, cancel := context.WithTimeout(context.Background(), time.Second)
    defer cancel()
    err := Serve(ctx, path)
    body, readErr := os.ReadFile(path)
    if err == nil || readErr != nil || string(body) != "keep" {
        t.Fatalf("startup replaced an unrelated file: serve=%v read=%v body=%q", err, readErr, body)

}
```
