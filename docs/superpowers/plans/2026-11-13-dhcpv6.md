# DHCPv6 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Kea DHCPv6 on LAN segments with a static IPv6 `/64`: address ranges, static leases by DUID, DNS options, prefix delegation with routes via the requesting router, lease names, and the advertisement modes that need it.

**Architecture:** A new `dhcp6` collection, like `dhcp`, whose versions live in a new `dhcp6_changes` table. The renderer writes `/run/andaru-kea/kea-dhcp6.conf`, an unreachable route for each delegation pool, the DNS service's IPv6 names and access list, and a fixed input rule. The generation starts or stops `kea-dhcp6-server` like the DHCPv4 server. `andaru realize leases` additionally publishes AAAA and PTR names and reconciles the delegated-prefix routes (protocol 188) from hook records it validates.

**Tech Stack:** Go, JSON Schema, SQLite, Kea 2.6 DHCPv6, systemd-networkd 257, nftables, Unbound, Proxmox lab.

**Spec:** `docs/superpowers/specs/2026-11-13-dhcpv6-design.md`

## Global Constraints

- **Names:**
  - collection `dhcp6`, ID prefix `dh6`;
  - API `/api/v1/config/dhcp6`, CLI `dhcp6`;
  - config file `/run/andaru-kea/kea-dhcp6.conf`;
  - control socket `/run/kea/kea6-ctrl-socket`.
- **Files and route protocol:**
  - hook event file `/run/kea/andaru-pd-events`, renamed to `/run/andaru-leases/pd-events` before reading;
  - next-hop table `/var/lib/andaru/pd-next-hops.json`;
  - route protocol `188`.
- **Values:**
  - `leaseTime` 300–604800, default 7200; preferred lifetime = valid × 5 / 8;
  - `delegatedLength` 48–64, longer than the pool prefix;
  - the event file is refused above 1 MiB, or when it is not a regular file owned by `_kea`.
- **No change without DHCPv6:** a declaration without `dhcp6` renders byte for byte as today, so existing goldens stay unchanged.
- **Tests:** `go test ./internal/...`. Goldens are refreshed with `-update`, and the diff is read before committing.

## Review Focus

1. **Hostile event file:** a symlink, a file of another owner, oversized input, or garbage lines must never make the root sync follow, read or believe them (Task 5).
2. **Route ownership:** a route of protocol 188 that matches no active, believed lease is removed. A route of any other protocol is never touched (Task 5).
3. **Reboot:** with an empty event file, the sync installs routes from the persisted table for leases Kea still lists (Task 5).
4. **Names:** a static DHCPv4 name does not stop the same device's dynamic AAAA record, and vice versa (Task 5).
5. **Old stores:** a store without `dhcp6_changes` opens and saves (Task 1).

**Interfaces:**
- Produces `dhcp6Entry{identity; Segment string; Ranges []dhcpRange; LeaseTime int; DNSServers []string; StaticLeases []staticLease6; PrefixDelegation *prefixDelegation}`.
- Produces `staticLease6{DUID, Address, Prefix, Hostname string}` and `prefixDelegation{Prefix string; DelegatedLength int; ExcludedPrefix string}`.
- Produces `servedV6Static(d, id) (netip.Prefix, bool)`: the first non-link-local `/64` of a `static` IPv6 segment.

    - unknown or non-static segment, at `/segment`;
    - a second entry for the same segment;
    - a range outside the `/64`, or one holding the segment's address;

### Task 5: Lease sync: AAAA names and delegated-prefix routes

**Files:** `internal/generation/leases.go` (v6 leases over `kea6-ctrl-socket`, AAAA and PTR records, names kept per family), a new `internal/generation/pdroutes.go` and `pdroutes_test.go`.

**Interfaces:**
- `func (r Realizer) syncRoutes(ctx context.Context, cfg kea6Config, leases []keaLease6) error`;
- the table file holds a JSON object from prefix to `{"via":"fe80::…","dev":"lan0"}`.

- [ ] **Step 1: Write the failing tests.** They use the fake Kea socket from the DHCPv4 tests, extended to v6, a fake event file, and the existing fake `Run`:
  - `TestPDEventInstallsRoute`: an `add fd00:beef:100::/56 fe80::1 lan0` record plus the active lease runs `ip -6 route replace fd00:beef:100::/56 via fe80::1 dev lan0 proto 188`, and the table holds it.
  - `TestPDEventRefusals`: none of these install a route:
    - an interface that is not served;
    - a next hop `2001:db8::1`;
    - a prefix outside the pool;
    - a lease Kea does not list;
    - a garbage line.
  - `TestPDEventFileHostile`: a symlink, a file owned by another user, and a 2 MiB file are each refused without being read; the sync continues with the table.
  - `TestPDRouteRemoval`: an `ip -6 route show proto 188` listing a prefix nobody leases leads to `ip -6 route del` for it only.
  - `TestPDRoutesAfterReboot`: no event file, a table entry, and an active lease give the route reinstalled.
  - `TestDHCPv6Names`: an IA_NA lease with a hostname gives AAAA and PTR. A static DHCPv4 name equal to it does not block the AAAA; a static DHCPv6 name does.
