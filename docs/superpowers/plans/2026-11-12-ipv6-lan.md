# IPv6 for the LAN Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Apply delegated prefixes and router advertisements (`router`, `unmanaged`) on LAN segments, with the WAN DHCPv6 client options, DNS over IPv6 on a stable unique local address, and the multicast listener filter rule.

**Architecture:** The saved declaration gains `ra.mode` and its options (old `{enabled, managed, otherInfo}` versions still load and are rewritten on the next write), stable addresses on `delegated` segments, and DHCPv6 client fields. The renderer turns them into networkd `[IPv6SendRA]`, `[IPv6Prefix]`, `[IPv6PREF64Prefix]`, `[DHCPPrefixDelegation]` and `[DHCPv6]` lines and Unbound listeners; the apply gates stop refusing delegated prefixes and advertisements.

**Tech Stack:** Go, JSON Schema (santhosh-tekuri/jsonschema v6), systemd-networkd 257, Unbound 1.26, nftables, Debian 13 lab on Proxmox.

**Spec:** `docs/superpowers/specs/2026-11-12-ipv6-lan-design.md`

## Global Constraints

- `schemaVersion` stays 1. A saved version written before this slice must still load: `history.go` rejects a version whose canonical re-encoding differs from its stored bytes, so the legacy `ra` form must round-trip byte for byte.
- `ra.mode` values: `disabled`, `router`, `unmanaged`, `managed`, `assisted`, `stateless`. Legacy mapping: `enabled:false` → `disabled`; `enabled:true` with `managed` → `managed`; with only `otherInfo` → `stateless`; otherwise `unmanaged`.
- Defaults: `priority` `medium`, `routerLifetime` 1800, `validLifetime` 86400, `preferredLifetime` 14400. `routerLifetime` is 0 or 4–9000.
- `pref64` lengths: 32, 40, 48, 56, 64, 96.
- `sendRelease` defaults to `false` and renders `SendRelease=no` on `dhcp6` segments.
- `managed`, `assisted`, `stateless` are refused at apply with `APPLY_UNSUPPORTED`; PPPoE stays refused.
- The tests run with `go test ./internal/...`; render goldens are rewritten with `go test ./internal/render -run TestNetworkGolden -update` and the diff is read before committing.

## Review Focus

1. A history containing a legacy `ra` object (both `enabled:false` and `enabled:true`) must still list and load: Task 1 pins it with a store round-trip.
2. A delegated segment without a stable address served by the DNS service: clients get no IPv6 resolver, and the warning must say why (Task 4).
3. Two segments delegated from the same upstream with `router` on one and `unmanaged` on the other: `Announce=` must follow each segment's own mode (Task 3).
4. A WAN on PPP with `withoutRA` also set must render `WithoutRA=solicit` once (Task 3).
5. Unbound must still start when the stable address is not yet on the interface (`ip-freebind`); the listener and `interface-action` must name the same address (Task 4, probed).
